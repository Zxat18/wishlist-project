# wishlist-project
## Описание
Проект для пересдачи по дисциплине "Основы веб-разработки"

## Функционал
- Добавление товаров с названием, ссылкой, ценой и категорией
- Валидация полей (проверка URL, цены, названия)
- Фильтрация по категориям (Электроника, Одежда, Книги, Другое)
- Поиск по названию товара
- Сортировка по цене и названию
- Подсчёт общей стоимости
- Сохранение данных в localStorage
- Адаптивный дизайн на Bootstrap 5

## Технологии
- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- GitHub Pages

## Как использовать
1. Откройте сайт: https://zxat18.github.io/wishlist-project/
2. Заполните форму добавления товара
3. Используйте фильтры и поиск для навигации
